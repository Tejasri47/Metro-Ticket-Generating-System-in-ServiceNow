# 🚇 Metro Ticket Generating System – ServiceNow

## 📌 Project Overview

The **Metro Ticket Generating System** is a ServiceNow-based digital metro ticket booking application designed to simplify the metro ticket booking process.

The system allows users to select their starting station, destination, journey type, number of passengers, and payment mode. The fare is calculated automatically, and a QR-based digital ticket is generated for the user.

## 🎯 Objectives

- Provide a simple digital metro ticket booking experience.
- Automatically calculate ticket fares.
- Support single and return journeys.
- Allow users to select the number of passengers.
- Provide different payment mode options.
- Generate a QR-based digital ticket.
- Automate the booking process using ServiceNow.

## ✨ Key Features

- 🎫 **Digital Metro Ticket Booking**
- 🚉 **Starting and Destination Station Selection**
- 🔄 **Single and Return Journey**
- 👥 **Multiple Passenger Selection**
- 💰 **Automatic Fare Calculation**
- 💳 **Payment Mode Selection**
- 📱 **QR-Based Digital Ticket**
- ⚙️ **ServiceNow Flow Automation**
